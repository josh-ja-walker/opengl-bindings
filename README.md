# OpenGL Bindings for ScalaNative

Bindings are generated by [sn-bindgen](https://sn-bindgen.indoorvivants.com/) from GLAD and GLFW libraries. The bindings target the Windows 64-bit hardware.

- [GLAD](https://github.com/Dav1dde/glad) is a Loader-Generator for GL/GLES/EGS/GLX/WGL and Vulkan.  
- [GLFW](https://www.glfw.org/) is an open-source multi-platform library for OpenGL.  
    It provides a simple API for creating windows, contexts and surfaces, receiving input and events.


## Usage

Add the following settings to `build.sbt`:

```scala
    /* Project Definition ... */
    .enablePlugins(ScalaNativePlugin, VcpkgNativePlugin)
    .settings(
        libraryDependencies  += "io.github.josh-ja-walker" %%% "opengl-bindings" % "CURR_VERSION",

        vcpkgDependencies := VcpkgDependencies("glfw3"),
        nativeConfig := {
            nativeConfig.value
                .withLinkingOptions(_ :+ "-lshell32") /* Link shell32 library for glfw function support */
                .withLinkingOptions(_ ++ vcpkgConfigurator.value.pkgConfig.linkingFlags("glfw3")) 
        }
    )
```

This adds the required `glfw3` [vcpkg dependency](https://vcpkg.io/en/package/glfw3.html) to the ScalaNative linking configuration, in addition to the `shell32` library required on Windows.


## Forwarders

Forwarders expose the C preprocessor `#define` constants used in the headers of the respective libraries. These have been detected using Regex and used to generate C forwarding functions. Scala extern functions then import these C forwarders.

The `#define` preprocessor directive is typically used for constants; GLAD uses the directive to define function pointers to `GL_` functions. This case is handled similarly.

Each Regex has an assumed default type for the defined constants: in GLAD, this is an `unsigned int`; in GLFW, this is an `int`.  
These types must be manually modified in some special cases:

### GLAD

- `GL_TIMEOUT_IGNORED` - this value is `0xFFFFFFFFFFFFFFFF`. It must be the largest unsigned integer type to avoid overflow.

    ```c
        /* const.c */
        unsigned long long CONST_GL_TIMEOUT_IGNORED() { return GL_TIMEOUT_IGNORED; } // defined as      0xFFFFFFFFFFFFFFFF - type adjusted to unsigned long long
    ```

    ```scala
        /* constants.scala */
        @name("CONST_GL_TIMEOUT_IGNORED") @extern def GL_TIMEOUT_IGNORED: CUnsignedLongLong = extern // defined as  0xFFFFFFFFFFFFFFFF - type adjusted to CUnsignedLongLong
    ```

- `GL_TRUE`, `GL_FALSE` - OpenGL function calls expect true and false values to be of type `GLboolean`, an alias for `unsigned char`.

    ```c
        /* const.c */
        unsigned char CONST_GL_TRUE() { return GL_TRUE; } // defined as 1 - type adjusted to char
        unsigned char CONST_GL_FALSE() { return GL_FALSE; } // defined as 0 - type adjusted to char
    ```

    ```scala
        /* constants.scala */
        @name("CONST_GL_TRUE") @extern def GL_TRUE: UByte = extern // defined as 1 - type adjusted to UByte
        @name("CONST_GL_FALSE") @extern def GL_FALSE: UByte = extern // defined as 0 - type adjusted to UByte
    ```
